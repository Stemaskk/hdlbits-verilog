# wire4

- **HDLBits link:** https://hdlbits.01xz.net/wiki/Wire4
- **Category:** verilog_language/basics

## Problem

Create a module with 3 inputs and 4 outputs that behaves like wires making these
connections: a -> w, b -> x, b -> y, c -> z.

## Notes

Order of `assign` statements doesn't matter — they describe connections, not
sequential steps.

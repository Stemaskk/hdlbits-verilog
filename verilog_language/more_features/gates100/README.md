# gates100

- **HDLBits link:** https://hdlbits.01xz.net/wiki/Gates100
- **Category:** verilog_language/more_features

## Problem

Build a combinational circuit with a 100-bit input and three outputs: a 100-input
AND, a 100-input OR, and a 100-input XOR.

## Notes

Same idea as [gates4](../../vectors/gates4/) — reduction operators (`&`, `|`, `^`)
scale to any width without writing out each bit.

# hadd

- **HDLBits link:** https://hdlbits.01xz.net/wiki/Hadd
- **Category:** circuits/combinational/arithmetic

## Problem

Create a half adder: add two bits (no carry-in) and produce a sum and a carry-out.

## Notes

`sum` is `a ^ b` and `cout` is `a & b`. A full adder ([fadd](../fadd/)) is the same
idea with a third input, `cin`.

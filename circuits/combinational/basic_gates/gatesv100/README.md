# gatesv100

- **HDLBits link:** https://hdlbits.01xz.net/wiki/Gatesv100
- **Category:** circuits/combinational/basic_gates

## Problem

Same as [gatesv](../gatesv/) (`out_both`, `out_any`, `out_different` between
neighboring bits), scaled up to a 100-bit input.

## Notes

Identical shifted-slice/rotation pattern as gatesv — the technique doesn't care
about width, only the offset between slices.

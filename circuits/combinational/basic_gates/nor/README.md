## Problem

Implement the circuit shown: a NOR gate over two inputs.

## Notes

Used logical operators (`!`, `||`) instead of bitwise (`~`, `|`) — equivalent here
since both inputs are single bits. Compare to [norgate](../../../verilog_language/basics/norgate/),
which used the De Morgan's Law form instead.

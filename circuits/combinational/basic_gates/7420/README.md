# 7420

- **HDLBits link:** https://hdlbits.01xz.net/wiki/7420
- **Category:** circuits/combinational/basic_gates

## Problem

Implement the 7420 chip: two independent 4-input NAND gates.

## Notes

Simpler than [7458](../../../verilog_language/basics/7458/) — no OR stage, just one
4-input AND negated per gate.

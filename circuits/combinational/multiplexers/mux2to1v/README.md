# mux2to1v

- **HDLBits link:** https://hdlbits.01xz.net/wiki/Mux2to1v
- **Category:** circuits/combinational/multiplexers

## Problem

Create a 100-bit wide 2-to-1 multiplexer: `sel=0` chooses `a`, `sel=1` chooses `b`.

## Notes

Same as [mux2to1](../mux2to1/) — the ternary condition is 1 bit regardless of the
width of the two values it's choosing between.
